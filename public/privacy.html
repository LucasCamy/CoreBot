Em resumo
  • Armazenamos apenas identificadores públicos do Discord (IDs de servidor, canal e usuário) e preferências configuradas.
  • Não lemos conversas privadas de texto nem gravamos ou escutamos áudio nos canais de voz.
  • Logs operacionais expiram em 14 dias; históricos de voz expiram em 90 dias.
  • Você pode solicitar acesso, exportação ou exclusão definitiva a qualquer momento via e-mail.

1. Quem somos

O Uganda Knuckles é mantido como projeto independente por Lucas Camy (lucascamy@hotmail.com). O projeto não possui vínculo societário ou institucional com a Discord Inc.

2. Dados que coletamos

Para prover os serviços contratados pelo servidor, coletamos apenas os dados estritamente necessários:

  • Identificadores Discord: ID do servidor (Guild ID), ID de canais, ID de cargos e ID de usuários;
  • Nomes públicos: Username e apelido do servidor (Server Nickname) quando vinculados a ações específicas (como presença em eventos, listas ou citações de pérolas);
  • Configurações do servidor: Canais designados para notificações de voz, regras de eventos, fuso horário escolhido e permissões administrativas internas;
  • Conteúdo voluntário: Títulos de eventos, frases cadastradas voluntariamente com /perola e itens de checklists coletivos;
  • Logs de telemetria operacional: Registros técnicos temporários de disparo de avisos e transições de entrada/saída de canais de voz.

O que NÃO coletamos: Mensagens de texto comuns do chat, fotos privadas, mensagens diretas (DMs), nem fluxo de áudio dos canais de voz. O bot apenas transmite som sob demanda, sem qualquer funcionalidade de escuta ou gravação.

3. Finalidade do uso dos dados

Os dados são processados exclusivamente para a execução das funcionalidades do bot:

  • Criar, gerenciar e deletar canais dinâmicos temporários;
  • Disparar avisos configurados de entrada/saída de voz nos canais de destino;
  • Controlar presenças e confirmações em lobbies e listas de eventos;
  • Garantir a integridade do sistema contra spam e abuso de requisições.

4. Período de retenção

Mantemos os dados somente pelo período indispensável para cada recurso:

  • Logs operacionais de notificação: Excluídos automaticamente após 14 dias;
  • Logs de atividade de voz: Excluídos automaticamente após 90 dias;
  • Configurações e dados estáticos (eventos, frases, notas): Armazenados enquanto o bot estiver presente no servidor ou até o comando explícito de remoção;
  • Remoção do servidor: Caso o bot seja expulso de um servidor, as configurações associadas podem ser expurgadas da base de dados mediante solicitação ou ciclo de manutenção.

5. Compartilhamento de dados

Não comercializamos, alugamos nem repassamos dados de usuários a terceiros para fins de marketing ou publicidade. Os dados transitam apenas entre o cluster de execução do bot, o banco de dados PostgreSQL seguro e as APIs oficiais do Discord.

6. Seus direitos (LGPD / GDPR)

Você tem o direito de solicitar a confirmação da existência de tratamento, o acesso aos dados armazenados, a correção de dados incompletos e a eliminação dos seus dados da nossa base. Basta enviar um e-mail para lucascamy@hotmail.com informando seu Discord User ID.

7. Segurança da informação

Adotamos medidas técnicas de segurança, incluindo comunicação criptografada via HTTPS/WSS com o Discord, isolamento de banco de dados em rede privada (Kubernetes/k3s) e restrição de acesso por chaves seguras.

8. Menores de idade

O bot segue a faixa etária mínima exigida pelos termos de uso do Discord (13 anos ou a idade legal exigida em seu país). Não coletamos conscientemente dados de crianças menores de 13 anos.

9. Atualizações desta política

Esta política pode ser revista a qualquer momento. Alterações substanciais serão refletidas pela data de atualização no cabeçalho desta página.

10. Canal de contato

Para dúvidas, requisições de privacidade ou contato direto com o responsável, escreva para: lucascamy@hotmail.com.
